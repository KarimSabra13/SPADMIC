# Analog GPIO CSR Map

Status: v1 CSR map for SLVS/receiver/tap-monitor controls.

## Register

`SPADMIC_CSR_SLVS_GPIO_CTRL = 16'h7010`

Access: read/write through the existing matrix-top CSR path. Writes are allowed
during acquisition bring-up and are blocked only by global reset.

| Bits | Output | Reset | Notes |
| --- | --- | --- | --- |
| `[3:0]` | `slvs_s_drv_o[3:0]` | `4'h0` | SLVS driver strength/select |
| `[4]` | `slvs_en_vref_ext_o` | `1'b0` | enables use of external VREF where macro supports it |
| `[5]` | `slvs_en_drv_o` | `1'b0` | SLVS driver enable |
| `[6]` | `slvs_vref_adj_b_o` | `1'b0` | analog active-low polarity to be confirmed; no digital inversion |
| `[7]` | `slvs_en_vref_400mv_o` | `1'b0` | internal 400 mV VREF enable |
| `[8]` | `slvs_en_ref_drv_b_o` | `1'b0` | analog active-low polarity to be confirmed; no digital inversion |
| `[12:9]` | `rx_s_rx_o[3:0]` | `4'h0` | receiver select/trim |
| `[13]` | `rx_en_rx_o` | `1'b0` | receiver enable |
| `[14]` | `rx_en_term_o` | `1'b0` | receiver termination enable |
| `[31:15]` | reserved | `0` | read as zero, write ignored |

## Routing Intent

These are internal digital-top outputs, not direct pads. The final chip wrapper
routes them to DDRs2 and TXRX4TDC where those macros expose matching control
terms.

`PAD_VREF_EXT` is separate. It is a real external analog pad and is not
generated by this CSR.

## Polarity Rule

The `_B` signals are stored and output exactly as written. The digital logic
does not invert them. If the analog designer requests different safe reset
values for active-low controls, update reset defaults only; do not silently
change the CSR bit polarity.
