# SPADMIC Generated Work Area

This directory is the standard root for generated MPTDC outputs.  It is ignored
by git except for this README.

Expected subdirectories:

```text
work/
  genus/
  innovus/
  xcelium/
  verilator/
  characterization/
  calibration/
  plots/
  logs/
  evidence/
  scratch/
```

Keep RTL, constraints, scripts, macro abstracts, XLIBD inputs, and curated
markdown summaries in git.  Keep run directories, logs, reports, waveforms,
checkpoints, databases, huge CSVs, tarballs, and plots generated from a run in
this tree or in external artifact storage.
