## Scope

O6 characterization must prove measurement behavior before the next Genus run.
The production output packet format is frozen for this work package. Internal
tag encoding may change only if the same packet fields, widths, word count, and
parser contract are preserved and the run manifest declares the encoding.

## Internal Records

Package source: `MPTDC/rtl/pkg/mptdc_pkg.sv`

Current dimensions:

| Item | Width | Notes |
|---|---:|---|
| `NE` | 8 | 8 slow phases x 8 fast phases |
| `PD_N` | 64 | PD matrix cells |
| `PH_W` | 3 | internal `ns` and `nf` phase indices |
| `NSLOW_W` | 7 | packet-visible slow epoch count |
| `NFAST_W` | 7 | packet-visible fast field |
| `EVENT_SEQ_W` | 4 | supports up to 15 hits |
| `PACKET_CTX_W` | 2 | frozen header allocation |
| `STOP_PHASE_DISC_W` | 3 | Hit W1 slow STOP discriminator |
| `NARROW_W` | 16 | production output word width |

Internal HIT acquisition record:

```text
mptdc_hit_raw_t:
  ns        : PH_W = 3 internal bits
  nf        : PH_W = 3 internal bits
  nfast     : NFAST_W = 7 bits
  event_seq : EVENT_SEQ_W = 4 bits
```

Internal META acquisition record:

```text
mptdc_conv_meta_t:
  nslow                 : 7 bits
  nfast                 : 7 bits, phase-0 compatibility tag/count field
  nfast_stop            : 7 bits, retained compatibility field
  hit_count             : 4 bits
  flags                 : 4 bits
  phase0_snap           : 1 bit
  stop_slow_phase_disc  : 3 bits
  slow_boundary_inc     : 1 bit
  ctx_id                : CTX_W = 1 internal bit, padded in packet
```

Context snapshot record:

```text
mptdc_ctx_snapshot_t:
  hit_level          : 64 bits
  nfast_hit_packed   : 64 x 7 bits
  nslow_snap         : 7 bits, decoded from STOP-captured slow Johnson
  nfast_snap         : 7 bits, currently raw phase-0 fast tag compatibility field
  nfast_stop         : 7 bits, currently zero in the active architecture
  phase0_snap        : 1 bit
  stop_phase_disc    : 3 bits
  slow_boundary_inc  : 1 bit
  hit_count          : 4 bits
  flags              : 4 bits
```

## Production Narrow Packet

Serializer source: `MPTDC/rtl/readout/mptdc_narrow16_tx_v2.sv`

One conversion emits:

```text
1 x HEADER
hit_count x HIT_W0
hit_count x HIT_W1
1 x EOC
```

There are no subheaders and no variable-width hit records in the maintained
production packet.

Header word:

```text
[15:14] = 2'b10
[13:12] = ctx_id padded to two packet bits
[11]    = phase0_snap
[10:7]  = hit_count
[6:3]   = flags
[2]     = slow_boundary_inc
[1:0]   = reserved, read as zero
```

HIT W0:

```text
[15]    = 1'b0
[14:8]  = nslow[6:0]
[7:1]   = nfast[6:0]
[0]     = 1'b0
```

HIT W1:

```text
[15]    = 1'b0
[14:11] = ns packet field, active values 0..7
[10:7]  = nf packet field, active values 0..7
[6:3]   = reserved, read as zero
[2:0]   = stop_slow_phase_disc
```

EOC word:

```text
[15:14] = 2'b11
[13:0]  = conv_id[13:0]
```

The production packet compatibility requirement for O6 is:

- no new production words
- no removed words
- no changed word marker
- no changed bit positions
- no changed `nslow`, `nfast`, `ns`, `nf`, `hit_count`, `flags`,
  `slow_boundary_inc`, `stop_slow_phase_disc`, or `conv_id` widths

## Current Drain Semantics

Drain source: `MPTDC/rtl/ctrl/mptdc_drain_ctrl.sv`

Current HIT emission:

```text
raw_tag = snapshot_i.nfast_hit_packed[pd_scan_idx*NFAST_W +: NFAST_W]
hit_rec.hit.nfast = raw_tag
```

There is no RTL fast-tag decode in the drain path. The field name remains
`nfast`, but in raw-tag modes this is an encoded fast tag, not a binary fast
cycle count.

Current `nslow` handling:

```text
STOP captures raw 64-stage slow Johnson state.
clk_sys bridge decodes it to nslow_snap[6:0].
packet HIT W0[14:8] carries decoded nslow.
```

## Encoding Semantics

Supported encoding labels after the O6 software update:

```text
legacy_binary_nfast:
  packet nfast field = legacy binary fast count
  decode mode = identity

raw_lfsr_tag:
  packet nfast field = raw 7-bit Fibonacci LFSR tag
  decode mode = software
  table = tools/mptdc_decode/fast_tag_decode.py, raw_lfsr_tag

raw_galois_tag:
  packet nfast field = raw 7-bit Galois LFSR tag candidate
  decode mode = software
  table = tools/mptdc_decode/fast_tag_decode.py, raw_galois_tag
```

`raw_galois_tag` is a candidate software/manifest mode only until matching RTL
is intentionally enabled. Do not label current Fibonacci-LFSR RTL data as
`raw_galois_tag`.

## Allowed Internal Changes

The following may change internally if documented and characterized:

- fast tag next-state implementation
- fast tag decode table
- fixed decode offset model
- clk_sys pipeline staging
- analysis/calibration metadata

The following must not change externally in O6:

- production packet word count rules
- production HIT/META/EOC bit layout
- `nfast` packet field width
- `nslow` packet field width
- `ns`/`nf` packet field widths
- context/drain/readout ordering
- raw-feature CSV base columns

## Characterization Gate

Genus remains blocked until at least:

- Stage 0 local/unit regression passes
- Stage 1 Xcelium packet/functional smoke passes
- Stage 2 medium characterization passes
- packet parser confirms the same production format
- analysis manifest records branch, RTL HEAD, packet format version,
  `nfast_encoding`, tag type, tag width, tag columns, decode mode, and decode
  table hash

Do not mix `legacy_binary_nfast`, `raw_lfsr_tag`, and `raw_galois_tag` datasets
without explicit manifest metadata.
