# MPTDC Product-Only Shared Cleanup Audit

Date: 2026-06-15
Branch at audit start: `SPADMIC_test`

This audit records the grep evidence used before converting the active SPADMIC
TDC path from exported acquisition records to direct product packet streams.
Generated build outputs under `TOP/build/**` are excluded from classification;
they are regenerated by the simulation runners and should not drive source RTL
ownership decisions.

## Active Product Path Before Cleanup

The active chip path is:

1. `TOP/rtl/spadmic_top_v1.sv` instantiates three
   `spadmic_tdc_axis_wrapper` axes.
2. Each axis wrapper instantiates `mptdc_top_asic` with
   `shared_readout_en_i=1`, ties off local `narrow_*`, and exports `acq_*`.
3. `arb/rtl/spadmic_correlated_tx.sv` instantiates three
   `spadmic_tdc_packet_adapter` blocks to serialize `acq_*` into 16-bit packet
   words.
4. `spadmic_correlated_tx` arbitrates the TDC and position packet streams, then
   overwrites EOC words with the unified TOP event ID.

## Source Header Patch Note

The old TOP adapter patched TDC source ID into header bits `{word[6],
word[12]}`. Product protocol cleanup changes TDC source decode to header
`[1:0]`, while `mptdc_packet16_tx` emits generic header `[1:0]=2'b00`.
`spadmic_correlated_tx` must therefore patch header `[1:0]` at SOP only and
must leave HIT, EOC, and position words untouched.

## Implemented Product Path After Cleanup

The active chip path after this cleanup is:

1. `TOP/rtl/spadmic_top_v1.sv` instantiates three
   `spadmic_tdc_axis_wrapper` axes plus three TOP-owned
   `spadmic_tdc_axis_csr` blocks.
2. Each axis wrapper instantiates `mptdc_axis_core`, which owns input muxing,
   reset synchronization, `mptdc_core`, and direct product packet emission.
3. `mptdc_core` no longer exposes `shared_readout_en_i`, `acq_*`, `narrow_*`,
   or local CSR/readout compatibility ports.
4. `mptdc_packet16_tx` emits direct 16-bit packet words with SOP/EOP,
   `packet_active`, and `packet_pending` sidebands.
5. `spadmic_correlated_tx` consumes the three direct TDC packet streams and the
   position packet stream, patches only TDC header bits `[1:0]`, and overwrites
   all EOC payloads with the unified TOP event ID.
6. Product filelists compile `mptdc_axis_core` and exclude the deleted
   standalone/legacy modules listed in this audit.

## Files Excluded From Source Decisions

Grep finds stale references under generated build directories such as
`TOP/build/directed/**/mptdc.f` and `TOP/build/vip/**/mptdc.f`. These are
simulation artifacts generated from source filelists by the runners, so they are
not edited directly in this cleanup.
