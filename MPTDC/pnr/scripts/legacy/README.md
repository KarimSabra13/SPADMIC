# Legacy Innovus Wrappers

Stable user-facing Innovus commands are:

- `MPTDC/pnr/scripts/server_run_innovus_mptdc_feasibility.sh`
- `MPTDC/pnr/scripts/server_run_innovus_mptdc_typical.sh`

Historical experiment wrappers remain in `MPTDC/pnr/scripts/` until references
are updated and the stable flow is validated on the server.  Do not use
historical wrapper names in new user-facing documentation.
