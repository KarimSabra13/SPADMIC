# Legacy Genus Wrappers

Stable user-facing Genus commands are:

- `MPTDC/syn/scripts/server_run_genus_mptdc_typical.sh`
- `MPTDC/syn/scripts/server_run_genus_mptdc_timing_closure.sh`
- `MPTDC/syn/scripts/server_run_genus_mptdc_final_typical.sh`

Historical experiment wrappers remain in `MPTDC/syn/scripts/` until every
reference is updated and a server rerun validates the stable names.  Do not use
historical wrapper names in new user-facing documentation.
